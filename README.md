# toys-tore-E-commerce
E-commerce Sales Analysis
Project Overview

This project uses MySQL to analyze toystore sales data and answer business questions related to product performance, store performance, profitability, inventory, and sales trends.

Objective

The goal of this analysis is to identify patterns in sales performance and provide insights that could support business decision-making.

Tools Used
MySQL
SQL
Business Questions
Product Performance
Which products sell the most units?
Which products generate the most revenue?
Which products are the most profitable?
Which products have high sales but low profit margins?
Which products have low sales but high profit margins?
Store Performance
Which stores generate the most revenue?
Which stores generate the most profit?
Which stores are performing below average?
Which stores have the highest sales volume?
Inventory
Which products currently have the most inventory?
Which products are at risk of stockouts?
Which products are potentially overstocked?
Sales Trends
Which months generate the highest revenue?
Which products are growing or declining over time?
How does sales performance change over time?
